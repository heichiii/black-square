# 黑色矩形窗口 (Black Square)

一个始终置顶的黑色矩形窗口应用，即使其他应用全屏放视频或游戏，它也会始终显示在最前面。

## 功能特性

- ✅ **黑色矩形窗口** - 纯黑色背景
- ✅ **始终置顶** - 使用 Windows API 确保窗口始终在最前面
- ✅ **可调整大小** - 拖动窗口边框到调整大小
- ✅ **可调整位置** - 拖动标题栏移动位置
- ✅ **全屏穿透** - 即使其他应用全屏，也能显示在上方
- ✅ **快速退出** - Press `Ctrl+Q` to exit

## 系统要求

- Windows 10 / Windows 11
- Python 3.8+
- tkinter（通常与 Python 一起安装）

## 安装

```bash
# 仅需要 Python 标准库，无需额外依赖
python main.py
```

## 使用方法

1. 运行程序：
   ```bash
   python main.py
   ```

2. 调整窗口：
   - 拖动边框调整大小
   - 拖动标题栏移动位置
   - 最小化/最大化按钮正常工作

3. 退出应用：
   - 按 `Ctrl+Q` 快速退出
   - 或点击关闭按钮

## 技术实现

- 使用 **tkinter** 创建 GUI 窗口
- 使用 **ctypes** 调用 Windows API (`SetWindowPos`)
- 周期性检查并重新设置窗口为 `HWND_TOPMOST` 以确保始终置顶

## 注意事项

- 在某些全屏应用（如游戏、视频播放器）中，Windows 可能会强制将其应用窗口放在最前面。此时可能需要调整系统设置或运行模式。
- 某些防病毒软件可能会对 Windows API 调用进行限制。
